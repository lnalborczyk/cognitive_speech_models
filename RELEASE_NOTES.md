# Release notes — 1.3.0

- Public models reduced to DIVA and Task Dynamics; other placeholder controllers removed.
- Default auditory feedback gain set to zero; optional experimental feedback remains available.
- VTL speaker vowel-reference calibration with numerical repeatability reporting.
- Temporal resonance anchoring across observer updates; unresolvable peaks remain missing.
- Gain/delay grid for unperturbed tracking (one fixed seed) and paired-F1 compensation reporting.
- Direct downloads for all three feedback-ablation WAV files.
- Public-facing README and revised model/synthesis documentation.

All controller comparisons remain exploratory rather than validated reproductions of published architectures.
